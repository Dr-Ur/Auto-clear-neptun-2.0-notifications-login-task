Tampermonkey userscript, amely bejelentkezés után automatikusan megnyitja és elolvasottként jelöli az új Neptun kötelezően elolvasandó értesítéseit, lehetővé téve a home page gyors elérését.


Fő funkciók:

  - Értesítések automatikus megnyitása és megerősítése
  
  - SPA / Angular kompatibilis (oldalfrissítés nélkül is működik)
  
  - Munkamenetenként csak egyszer fut
  
  - Progress bar
  
  - Manuális indítás hiba esetén


Telepítés:

 1. Telepítsd a Tampermonkey bővítményt. (https://www.tampermonkey.net/)
    
 2. Nyisd meg ezt a fájlt:   neptun-auto-clear.user.js
    
 3. Kattints az Install gombra


Használat:

  - Jelentkezz be a Neptunba
  
  - Az értesítések oldalon a script automatikusan lefut
  
  - Sikeres futás után a progress bar magától eltűnik.


Kompatibilitás:

  - Neptun Web 2.0 (hallgatói felület)
  
  - Chromium és Firefox alapú böngészők


Használd saját felelősségre.
